Hydrologist's page

This page explains the groundwater model outputs needed to run Forever Fair. The auction uses a linearized hydrology representation: each accepted bid affects one or more control-point constraints through response factors.

Minimum requirements before operation

  • Defined environmental limits and operational constraints.
  • A calibrated groundwater model suitable for response-matrix extraction.
  • Control points with defensible head limits.

Your groundwater model

You need a groundwater model that can produce a response matrix or equivalent linear influence coefficients between pumping decisions and head outcomes. A GWM2K or MODFLOW-based workflow is suitable when it can produce MPS-compatible information for constraints and decision variables.

Reference: USGS MODFLOW.

Quality checks recommended

  • Confirm sign convention for response factors and bounds.
  • Check that period indexing is consistent across all files.
  • Verify each active well has coefficients for each required control point and period.
  • Validate that bound values and units match bid quantities.
  • Run a small known case and compare prices and accepted quantities with independent calculations.

Environmental Standards to Encode Explicitly

The historical Forever Fair design emphasized entering quantitative standards first, then clearing the auction only within those limits. Typical standards include:

  • Head-difference constraints to preserve flow direction.
  • Drawdown limits to protect aquifer condition.
  • Minimum flow requirements for connected surface waters.
  • Location-specific restrictions near sensitive zones.

Time-Lag Requirement

Hydrologic effects propagate over time. The model should support lagged responses so present pumping can constrain future periods. This is why the data model should preserve pumping-period and effect-period indexing, not just same-period coefficients.

Importantly, both the pumping period and the effect period are relative offsets, not calendar dates. Period 1 means the first period of a given auction, regardless of when that auction runs. The same response factor table is therefore valid for any auction — the physics of the aquifer do not change with the auction schedule. This is why response factors are stored once and shared across all auctions, rather than being duplicated per auction.

Practical Modeling Note

An approximate model can still improve allocation compared with fixed quotas, if assumptions are documented and updated. Price signals then identify where better hydrologic resolution is most valuable.

The Linear Program for the Water Market

The following is the mathematical formulation of the Forever Fair market-clearing model, from Raffensperger (2008). This is what the software solves at each auction run. It is included here so hydrologists can confirm that their model outputs correspond to the correct parameters.

Indices

bbid, b = 1, …, 5
i, j, kwell or location, i = 1, …, n
u, ttime periods, t = 1, …, T. Period 1 is the present period.

Parameters

nnumber of locations
Fijtdrawdown response at location j, time t, for a unit drawdown at location i, time 0
Pitbreservation price for bid quantity b at location i, time t. Positive for buyers, negative for sellers!
Qitbbound on marginal bid b for water at location i, time t. If Qitb < 0, the bid is to sell. If Qitb > 0, the bid is to buy.
Ritresource consent at location i, time t
HNiunmanaged natural head at location i, if no wells are used
H0iinitial head at location i
LHitlower bound on head at location i, time t
UHitupper bound on head at location i, time t
LHDijtlower bound on head difference between locations i and j, time t
UHDijtupper bound on head difference between locations i and j, time t
Tnumber of time periods, probably 2 or 3

Variables

biditbquantity of bid b accepted for location i, time t
pitmarket price for a unit of water at location i, time t. Dual price on constraint 3.
qitwell abstraction rate at location i, time t, ≥ 0
sittotal drawdown response at location i, time t, as a result of all drawdowns: sit = ∑j=1..n ∑u=1..t Fiju qju

Model WaterMarket

1. Objective. Maximise consumer surplus plus producer surplus:

max ∑i=1..n ∑t=1..T ∑b=1..5 Pitb · biditb

2. Bid bounds. Bids are bounded by the marginal quantities in the tranches. Sell bids are negative quantities. Buy bids are positive quantities. For all b, i, t:

If Qitb < 0 : Qitb ≤ biditb ≤ 0 If Qitb > 0 : 0 ≤ biditb ≤ Qitb (Dual variables αitb)

3. Resource-consent balance. Well abstraction plus bid amounts equals the resource consent. The dual variable pit is the ($ gain) per unit increase of the resource consent. For all i, t:

qit + ∑b=1..5 biditb = Rit (Dual variables pit)

4. Drawdown balance. For all i, t:

∑j=1..n ∑u=1..t Fiju qju − sit = 0 (Dual variables sit)

5a. Head bounds relative to unmanaged head. For all i, t:

HNi − UHit ≤ sit ≤ HNi − LHit

5b. Head bounds relative to initial head. For all i, t:

H0i − UHit ≤ sit ≤ H0i − LHit (Dual variables λLit and λUit)

6. Head-difference constraints. To create gradient constraints, parameters can be scaled by distance. To create velocity constraints, scale by hydraulic conductivity, porosity, and retardation. For all i, j, t:

LHDijt − HNi + HNj ≤ −∑k=1..n ∑u=1..t (Fiku − Fjku) qku ≤ UHDijt − HNi + HNj (Dual variables dLijt and dUijt)

7. Non-negativity. qit ≥ 0, sit ≥ 0. biditb bounded by constraint 2.

Explanation

  1. Maximise consumer surplus plus producer surplus.
  2. Bids bounded by marginal quantities in each tranche. Sell bids are negative; buy bids are positive.
  3. Well abstraction plus bid amounts equals resource consent. Dual variable pit is the marginal value of the consent at location i, period t.
  4. Balance of flow at location i, time t.
  5. Lower and upper bounds on well heads. 5a is relative to unmanaged head; 5b is relative to initial head.
  6. Head-difference constraints. Vertical gradient constraints cannot be defined directly with the software, but head constraints can be used in place of them.

Dual linear program to WaterMarket

7. Dual objective. Minimise:

∑i,t { ∑b=1..b1 αitb Qitb − ∑b=b1+1..5 αitb Qitb + λLit(Hi − LHit) + λUit(−Hi + UHit) + ∑j [ dLijt(−LHDijt + Hi − Hj) + dUijt(UHDijt − Hi + Hj) ] }

8–9. Dual bid constraints. For buy bids (b = 1, …, b1) and sell bids (b = b1+1, …, 5), all i, t:

αitb + pit = Pitb (Dual variable biditb = 0)

10. Dual abstraction constraint. For all i, t:

pit + ∑u=t..T { ( ∑j Fji sit / Fii1 ) + ∑k,j (Fki − Fji)(dLkju − dUkju) } = 0 (Dual variable qit = 0)

11. Dual drawdown constraint. For all i, t:

pit / Fii1 + λLit − λUit = 0 (Dual variable sit = 0)

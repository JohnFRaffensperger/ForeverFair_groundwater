Responsibilities

  • Confirm legal and policy authority before operation.
  • Confirm rights registry and participant setup are correct.
  • Confirm hydrology constraints are current and defensible.
  • Operate auction setup, clearing, and reporting steps.

Recommended operating cycle

  1. Load or refresh hydrology data for the case.
  2. Set up the next auction and periods.
  3. Open trader participation window.
  4. Run clearing when bidding closes.
  5. Publish results and archive diagnostics.
  6. Prepare updates for the next period using observed inflows and new data.

Economic configuration principle

The target configuration is trader-trades, not government-profit. Under proportional rights adjustment, payments by buyers are offset by receipts to sellers, with only explicit operating fees retained for market administration.

Risk controls to add soon

  • Draft or tentative status before opening an auction.
  • Formal validation framework for all setup and import operations.
  • Cash transaction ledger and participant balances.
  • Clear role separation between manager and trader permissions.

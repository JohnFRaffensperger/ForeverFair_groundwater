The Auction Manager's responsibilities

  1. Have your hydrologist load updated head limits for the forecasted inflows. Confirm hydrology constraints are current and defensible.
  2. Set up the auction and run it.
  3. After the auction closes, run the auction.
  4. Check that traders took only the water for which they have quota.

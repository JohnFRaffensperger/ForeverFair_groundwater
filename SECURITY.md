# Security Policy

## Scope

This version of Forever Fair is a demonstration system.
It is not production-hardened by default.

## Reporting a vulnerability

Please report suspected security issues privately:

- Email: john.raffensperger@gmail.com
- Website contact: https://john.raffensperger.org

When reporting, include:

1. A description of the issue.
2. Steps to reproduce.
3. Impact assessment (what data or behavior is affected).
4. Any suggested mitigations.

Please do not open public issues with exploit details before maintainers have had time to assess and respond.

## Response targets

Best effort targets:

- Initial acknowledgment: within 7 days.
- Triage decision: within 14 days.
- Remediation timeline: shared after triage based on severity and project capacity.

## Known security limitations

This project includes known demo-oriented limitations:

- simplified authentication flows for trader/admin pages,
- no production deployment defaults,
- no guarantee of hardening for internet-exposed use.

For deployment hardening guidance, see the database documentation security section in the running app.

# Code of Conduct

## Our commitment

In the interest of fostering an open and welcoming environment, contributors and maintainers pledge to make participation in this project a harassment-free experience for everyone.

## Expected behavior

- Be respectful and constructive in discussions and reviews.
- Focus on evidence, reproducibility, and technical merit.
- Assume good intent and ask clarifying questions before escalating.
- Accept feedback gracefully and revise work when needed.

## Unacceptable behavior

- Harassment, intimidation, or personal attacks.
- Discriminatory language or conduct.
- Publishing private information without explicit permission.
- Sustained disruptive behavior in project discussions.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this code of conduct.
They may remove, edit, or reject comments, commits, code, wiki edits, issues, and other contributions that violate this Code of Conduct.

2 Set up
2.1 Your hydrology model
Start with your groundwater model. From the groundwater model, GWM2K (or similar) can create a linear program file in MPS format. This MPS file includes the response matrix, head constraints, and decision variables. It sets up the main structure of the auction clearing model. This eases setting up the trading system!  You are responsible for ensuring the validity of the response matrix.

Participants take water from one or more wells.
The response matrix implies an auction schedule.  Each auction trades water for one or more periods, which you choose. A period is most likely a day or a week. A period is the time denominator for traded water, e.g., ML/day or ML/week. For example, an auction cleared tomorrow might allow trading of water for the next four weeks.

2.2 Environmental requirements
You specifiy environmental requirements with head constraints. The catchment has control points where head must be constrained, such as to ensure a wetland does not run dry. The model must have a head limit for each control point.
You can choose to include some or all wells in the list of control points to make sure those wells have sufficient head.

3 Auction operation
Water allocated for the immediate period is real water. The auction manager must commit to letting people take that water.
Water scheduled for future periods is subject to scaling, because inflows may not match the forecast.
